## 📌 Project Overview

**AI-Based Work Planner and Productivity Tracker** is an intelligent productivity management application developed using **Flutter and Dart**, with **Firebase** as the backend platform.

The application helps users create, organize, schedule, prioritize, and monitor their daily tasks. It also uses **AI-based task analysis** to identify urgent tasks and provide intelligent priority recommendations.

The system combines task management, calendar scheduling, reminders, productivity tracking, Firebase Authentication, Cloud Firestore, and AI services into a single user-friendly application.

---

## 🎯 Objectives

- 📋 Simplify daily task management
- ⏰ Help users manage deadlines and schedules
- ⭐ Prioritize important and urgent tasks
- 🤖 Provide AI-based task recommendations
- 📊 Track completed and pending tasks
- 📅 Provide calendar-based task scheduling
- 🔔 Support task reminders and notifications
- 🔐 Provide secure user authentication
- ☁️ Store and synchronize data using Firebase

# ✨ Features

## 🔐 User Authentication

- User registration
- Email and password login
- Firebase Authentication
- Secure user sessions
- New users must log in after registration
- Logout functionality
- Separate user and admin access

---

## 📝 Task Management

Users can create tasks with:

- Task title
- Description
- Category
- Priority
- Due date
- Due time
- Reminder

### Task Operations

- ➕ Add task
- ✏️ Edit task
- 🗑️ Delete task
- ✅ Mark task as completed
- 📋 View pending tasks
- ✔️ View completed tasks

---

## ⭐ Task Priority

Tasks can have three priority levels:

| Priority | Description |
|---|---|
| 🔴 High | Urgent or important tasks |
| 🟠 Medium | Normal priority tasks |
| 🟢 Low | Less urgent tasks |

---

# 🤖 AI-Based Task Prioritization

The AI component analyzes task information and recommends an appropriate priority.

### AI analyzes:

- Task title
- Description
- Selected priority
- Category
- Due date
- Due time
- Remaining time
- Completion status

### Example

```text
User Priority:
Low

Due Date:
Today

AI Recommendation:
